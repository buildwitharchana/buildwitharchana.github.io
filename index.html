PROJECT 01

Python-Based Customer Reporting Automation

Designed and implemented an automated reporting solution that collected customer data from three independent REST APIs, transformed and consolidated the data, applied customer-specific business rules, and generated the final CSV report.

I used Python Requests for API integration and Pandas for data transformation. Because the API calls were independent and primarily I/O-bound, I implemented ThreadPoolExecutor with configurable workers to execute requests concurrently.

I also introduced execution-time tracking across different stages to identify bottlenecks and improve processing efficiency. Cursor AI was used as a development assistant for code generation and refactoring, while I owned the architecture, validation and business logic.

Architecture: REST APIs → Concurrent Python Data Collection → Pandas Transformation → Business Rules → CSV Report

PROJECT 02

Sun Life RFP Test Automation Tool

Built an internal automation framework to validate Ushur extraction outputs against Sun Life's authoritative Master Keys Excel workbook.

I designed the solution as a three-stage pipeline. Node.js scripts preprocess and normalize raw UDE JSON. A post-processing layer enriches the data with UDT case and census information and generates QPS-shaped JSON. A Python comparison engine then validates field presence and data-type consistency against the Master Keys.

I created a Python orchestration layer to automate the complete workflow and exposed the solution through both a CLI and a local Flask web UI, allowing users to upload files, execute the pipeline and download the final Excel report.

Pipeline: UDE JSON → Node.js Preprocessing → UDT Enrichment → QPS JSON → Python Comparison Engine → Excel Report

Python Node.js Pandas OpenPyXL Flask CLI Automation

Production Incident

Pay in 3 — High-Impact Merchant Incident

A production incident that demonstrates technical troubleshooting, incident ownership, customer communication and risk mitigation.

Restoring a critical payment flow under pressure

Situation

A high-volume enterprise merchant experienced failures on the Pay in 3 payment option, creating immediate transaction impact.

Ownership

As the technical lead, I took ownership of the incident, coordinated the engineering team and focused first on minimizing customer and business impact.

Immediate Mitigation

We temporarily disabled Pay in 3 through merchant configuration while keeping the other payment methods available, preventing customers from repeatedly encountering failed transactions.

Root Cause

Investigation identified a deprecated JavaScript variable/function in the merchant's website implementation as the underlying cause.

Resolution

I coordinated a hotfix, validated the payment flow, released the fix to production and closely monitored transactions after deployment.

Aftercare

I provided a detailed RCA and transaction impact report and worked with the team to introduce additional monitoring, alerts and preventive measures.
